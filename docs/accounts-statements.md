# Accounts — which report does what

Plain guide for the **Accounts** tab.

**In the app:** Accounts → **Help**. It opens on the report you have selected.

## 3 easy steps

1. Choose a report from the Statement list.
2. Set the dates (or month for GST) if you see those boxes.
3. Click **Generate**. Some Books reports open by themselves — no Generate needed.

## Remember

- No data? Try a wider date range, or check that bills/vouchers exist for that period.
- **Cash Flow** always shows money in and out from day-to-day work.
- **Sales Reg.** under Accounts = sales vouchers. **Sales Register** under Compliance = item-wise sales with GST.

## Accounts

| Report | Shows | What to do |
|--------|--------|------------|
| Profit & Loss | Profit or loss for the period | Set From–To, Generate |
| Daily Status | One day’s accounts snapshot | Pick date; use shortcuts |
| Trading A/c | Gross profit from trading | From–To (Books) |
| Balance Sheet | Owns vs owes | To date / Generate |
| Cash Flow | Cash in and out | From–To → Generate |
| Ledger | One account’s entries | Open ledger or pick Type → Generate |
| Day Book | All entries for day/period | From–To or From day → Generate |
| Cash Book | Cash running balance | From–To |
| Bank Book | Bank running balance | From–To |
| Bank Recon | Match bank statement | Tick cleared lines, save balance |
| PDC | Future-dated cheques | Realise when cleared |
| Sales Reg. | Books sales vouchers | From–To |
| Purchase Reg. | Books purchase vouchers | From–To |
| Vouchers | Create / open vouchers | Open desk |
| Trial Balance | Debit = Credit check | From–To (Books) |
| Book products | Item stock in Books | Open item |
| Credit/Debit Notes | CN / DN | Create or refresh list |
| Data import | Miracle CMP upload | Upload .rar / .zip |

## Compliance

| Report | Shows | What to do |
|--------|--------|------------|
| Sales Register | Item-wise sales + GST | From–To → Generate |
| Distribution Register | Dealer / trade sales | From–To → Generate |
| Outstanding | Who still owes you | Collect on party/bill |
| Payment history | Money already received | From–To → Generate |
| Stock Summary | Stock qty and value | Generate |
| Fine Metal Ledger | Fine metal movement | From–To (casting) |
| GST Summary | Month GST totals | Month + Year → Generate |
| GSTR-2B Reconciliation | Portal 2B vs purchases | Upload portal JSON |
| GSTR-3B Computation | Estimated 3B figures | Month + Year → check before filing |
